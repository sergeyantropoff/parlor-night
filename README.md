# Parlor Night

Демо: [https://pn.antropoff.ru](https://pn.antropoff.ru)

Локальная гостиная: шахматы, русские шашки, го, домино, Уно, покер, дурак, блэкджек и преферанс на игровые фишки.
Шахматы считает Stockfish, шашки и го — собственный поиск. Во время партии не нужны внешние API и телеметрия.
Картинка и голос идут между браузерами. Сервер знакомит участников и, когда прямой путь закрыт, отдаёт им TURN.

## Запуск

```bash
cp .env.example .env
make up
```

Откройте http://127.0.0.1:8000 . Пока `ENV=local`, при старте создаются входы `admin` / `admin` и `user` / `user`.
Другие учётные записи администратор добавляет на странице «Гости». Самостоятельная регистрация по умолчанию выключена.

Полезные команды: `make down`, `make logs`, `make migrate`, `make test`, `make lint`, `make backup`.

Для проверок без Docker нужен Python 3.12:

```bash
make install
make test
```

## Стол

1. Создайте партию или позовите друга из списка.
2. В гостиной можно оставить вызов и сесть к тому, кто уже ждёт.
3. Код приглашения сажает второго игрока. Открытый стол — с человеком или с компьютером — может смотреть кто угодно, закрытый виден только сидящим за ним. Наблюдатели в созвон не входят.
4. Доска и карты обновляются сами, примерно раз в полторы секунды.
5. Камера и микрофон включаются кнопками на странице партии. Можно играть и без них.
6. Сообщения за столом и личные беседы сохраняются на сервере.

Фишки начисляются за победу и ничью. За проигрыш фишки не выдаются. Покер, блэкджек и преферанс используют банк из этих фишек. Денег в игре нет.
Покер, блэкджек и преферанс доступны после 18 лет: дату рождения игрок указывает в разделе «Возраст». Дурак бывает подкидным и переводным — вид выбирают при создании партии. Домино играется в линию, от двух до четырёх, без банка.

## Новая игра

Каталог лежит в `app/catalog.py`. Для новой игры добавьте туда название и модуль правил,
который умеет сдавать колоду, проверять ход и показывать игроку только его карты.
Взрослая игра помечается флагом `adult`.

## Переменные

`SECRET_KEY` длиннее 32 символов. Пример из `.env.example` годится только для `ENV=local`.
`DATABASE_URL`, `CHESS_ENGINE_PATH`, `COOKIE_SECURE`, `TRUSTED_HOSTS`, `ALLOW_REGISTRATION`, `ENGINE_MODE` и `TURN_*` описаны в `.env.example`.

Внутри пода веб-процесс один: `scripts/serve.py` запускает uvicorn с `--workers 1`. В кластере таких подов два.
Сокет созвона остаётся в поде, который принял браузер. Список участников и сигналы идут через Valkey, поэтому игроки с разных подов слышат друг друга.
`ENGINE_MODE=local` считает шахматы, шашки и го в процессе сайта. Так устроен `make up`.
`ENGINE_MODE=remote` кладёт позицию в очередь Valkey, а считает её отдельный под движков. Карточные партии этот под не вызывают.
Партии и сессии по-прежнему в PostgreSQL, поэтому выход и просроченная сессия действуют сразу.

Valkey также держит счётчики запросов, неудачных входов и отметки «игрок на месте».
Без `TURN_SECRET` и `TURN_HOST` браузер получает только публичный STUN. В кластере эти значения заданы: имя и пароль TURN живут час и подписываются HMAC.

## Проверки и копии

`make test` запускает pytest. Интеграционные тесты сами пропускаются, если PostgreSQL на порту из `TEST_DATABASE_URL` недоступен.
`make backup` сохраняет дамп в каталог `backups/`.

## Кластер

Сайт [pn.antropoff.ru](https://pn.antropoff.ru) работает в Kubernetes, пространство `parlor-night`.
Образ сайта — `hub.antropoff.ru/parlor-night/parlor-night`, образ coturn — `hub.antropoff.ru/parlor-night/coturn`.
Postgres остаётся `postgres:16-alpine`, Valkey — `valkey/valkey:8-alpine`.

Два пода сайта принимают гостей. Движки — один отдельный под. Coturn закреплён за узлом `worker01`, адрес `192.168.1.251`.
Белый адрес в `turn.externalIp` — `217.150.201.203`, A-запись `pn.antropoff.ru`. DNS остальных сайтов на этом адресе не меняется: coturn только называет его в кандидате реле.

На роутере к `192.168.1.251` проброшены UDP и TCP `3478`, TCP `5349` и UDP `49160–49260`.
TCP 80 и TCP 443 по-прежнему ведут на сайт. Защищённый TURN слушает `5349`, потому что `443` занят сайтом. Сеть, где снаружи открыт только `443`, реле не получит.
Coturn не открывает реле во внутренние сети, включая `192.168.0.0/16`.

`make deploy` с этой машины не используется: `docker buildx --push` в Harbor зависает.
Образ собирается в OCI-архив через `desktop-linux` и заливается в Harbor по TCP `192.168.1.3:443` с именем `hub.antropoff.ru`.
Сначала в реестр кладутся блобы и манифесты архитектур, затем индекс на тег времени UTC и на `latest`.
Дальше выпуск обновляется так, тег передаётся явно:

```bash
helm upgrade parlor-night deploy/helm/parlor-night \
  --namespace parlor-night \
  --set fullnameOverride=parlor-night \
  --set image.repository=hub.antropoff.ru/parlor-night/parlor-night \
  --set image.tag="$TAG" \
  --wait --timeout 6m
```

Секрет `parlor-night-env` при этом не перезаписывается.

## Ограничения

- Регламент ничьей в шашках: 30 полуходов без взятия и без хода простой шашки, плюс троекратное повторение. Подробности в `app/checkers/draws.py`.
- Компьютер в шашках — SimpleEngine из py-draughts. Пять уровней задают глубину и время. Если библиотека не вернула допустимый ход, ходит собственный поиск. Троекратное повторение считает регламент партии после хода.
- В онлайн-партии нет шахматных часов и автоматического присуждения при обрыве связи.
- Го — с человеком или с компьютером, доски 9×9, 13×13 и 19×19, подсчёт по площади и коми 7,5. Компьютер — собственный поиск с пятью уровнями, как в шашках; это не профессиональная программа го. Снимок партии читается из базы, поэтому его видят все поды сайта. Сокет стола по-прежнему только для видео игроков. Сигнал между подами несёт Valkey.
- Покер здесь — безлимитный техасский холдем до шести игроков. Уже начатая раздача без стека доигрывается прежним лимитом. Уно и дурак — до шести игроков. Блэкджек играется против дилера, преферанс — всегда на троих. Очки преферанса гостиная переводит в фишки по своим расценкам, это не турнирная пуля.
- Домино — набор double-six, от двух до четырёх. Двое берут по семь костей, трое и четверо — по пять. Первым кладут старший дубль. Пустая рука выигрывает сразу. Если пас обошёл стол, победа у меньшей суммы очков. Длинная линия складывается одной змейкой и не распадается на отдельные полосы. Свободной доски, анализа и разбора нет. Банка нет.
- В созвоне до шести игроков за столом. Наблюдатели в этот предел не входят: они только смотрят партию и не передают звук и видео. Поток либо прямой, либо через TURN. Микшера, который собирает всех в одну картинку, нет. Сеть с одним открытым портом 443 реле не получает.
- Lc0 и другие сети сюда не входят: для них нужны веса и часто видеокарта. Любой локальный UCI-движок можно указать в `CHESS_ENGINE_PATH`.
