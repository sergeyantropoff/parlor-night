Связаться с нами

У гостиной нет общей почты на сайте. Доступ открывает администратор, и с ним же решают вопросы учётки, правил и фишек.

Если вас ещё нет в гостиной

{% if site and site.registration_mode == "open" %}

Набор сейчас открыт: можно создать учётную запись. Если вас пригласили, откройте ссылку друга до регистрации — тогда будет видно, кто пригласил.

{% elif site and site.registration_mode == "referral" and can_register %}

Вас пригласили. Создайте учётную запись — гостиная запомнит, кто прислал ссылку. Если ссылка потерялась, напишите тому, кто её отправил.

{% elif site and site.registration_mode == "referral" %}

Регистрация открыта по ссылке друга. Откройте приглашение, затем создайте учётную запись. Если ссылки нет, доступ открывает администратор.

{% else %}

Сейчас гостиная закрыта для самостоятельной регистрации. Учётную запись создаёт администратор. Напишите тому, кто вас приглашал: он передаст просьбу или откроет доступ сам.

{% endif %}

Если вы уже вошли

{% if user %}

Вы в гостиной как {{ player_link(user.display_name, user.username, user.avatar, false, false, true) }}. Имя, дату рождения, тему и сторону по умолчанию можно поменять в настройках. Вопрос по правилам, чужому столу или фишкам адресуйте администратору, который открыл вам дом.

{% else %}

Войдите, если учётка уже есть. Дальше дату рождения и оформление стола меняют в настройках, а вопрос по правилам или фишкам задают администратору гостиной.

{% endif %}

О чём писать

  • Не открывается вход или потерян доступ к имени.
  • Нужно поправить дату рождения для покера, блэкджека или преферанса.
  • За столом мешают, и вечер стоит остановить.
  • Фишки сошлись не так, как обещает правила гостиной.

Деньги гостиная не принимает и не возвращает: фишки существуют только внутри партий.
